Built for make.fun's bounty: https://make.fun/bounty/token-radar-01

An entry for the make.fun bounty **"Build the best token launch radar"**.

Prelaunch Radar reads the sealed DefiLlama snapshot and writes a ranked, offline dashboard of every pre-token protocol in that snapshot. Model-implied value is a size curve fitted on the protocols that already trade a token (a token-launch scenario), multiplied by the share of similar peers that already record a token, then by an existing-token relationship adjustment when a name stem already has a token. That product is a model scenario, not a launch probability and not an airdrop claim. Every kept term is tested leave-one-out and walk-forward. Each row has a costed, timed farm plan on a snapshot-listed deployment, with drop computed on protocol-wide TVL, and a FARM / THIN / SKIP verdict under an additive hurdle: reward after fees must beat the T-bill alternative plus hands-on hours × $25. The page refits the size curve and recomputes every ranked row in the browser. It needs no network at runtime.

The snapshot is never copied into this repository. The shipped `vendor/makefun-board.ts` library is used byte for byte to build the dossier.

Everything runs on Node 22+ with native TypeScript type stripping: no installs, no build step, and only erasable TS syntax.

## The value model

Protocols the house watchlist rule would set aside (bridges, liquid staking, CEX, exchange prefixes, version markers, wrapped or staked names) are accounted for in the 758-protocol ledger and are not ranked. The board is every remaining protocol that records no token (198 rows): the 40 watchlist slugs, early protocols below the $50M floor, and off-list names that share a stem with a token already on record.

```
value_if_launches = exp(a + b × ln TVL)

  a, b are ordinary least squares on the 92 priced, non-set-aside comps.
  A flat median multiple is the baseline. The size curve is kept only because it
  lowers typical multiplicative miss on both leave-one-out and a walk-forward
  split (older dated comps price newer ones). Growth, age and chain count were
  tried and not kept.

token_odds = logistic P(a peer already records a token | years listed, ln TVL)

  Fitted on the 442 non-set-aside peers (244 already record a token). Terms are
  kept only if they lower Brier score on both 10-fold and walk-forward. This is
  the peers' record, not a forecast that this protocol will issue a token.

kinship_share = 0.5 when a token-recording peer shares a name stem of four or
  more letters (generic words dropped), else 1.

implied_value_usd = max(1, round(value_if_launches × token_odds × kinship_share))
```

Prediction intervals (P10–P90, P25–P75) and rank ranges come from 1,000 size-curve bootstrap refits and leave-one-out residuals. Coverage is reported as observed, and is not widened to hit the nominal 50% / 80% rates. Farm maths use a $10,000 deposit, a 7% depositor share of model-implied value and a 12-week horizon, on a preferred chain that the snapshot actually lists for that protocol. FARM under stated assumptions means reward after fees beats the 4% T-bill alternative plus $25 times hands-on hours. THIN means the incremental return after the T-bill is positive but the opportunity-adjusted hourly return is at or below $25. SKIP means the incremental return is not positive.

## Run

From this directory:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```

`--input` may be a snapshot file or a directory containing `snapshot.json`; it defaults to `/input`. `--output` defaults to `$MAKEFUN_OUTPUT_DIR`, then `/output`. With the same input the generated bytes are identical on every run.

Open the dashboard by serving `out/dashboard` locally. It loads `z-data.js` with a relative script tag and makes no network requests. Hash routes are `#board`, `#p/<slug>`, `#detail/<slug>`, `#filter/farm`, `#filter/watch`, `#comps` and `#method`.

Farm verdicts use an additive T-bill-plus-labour hurdle.

## Screenshots

`tools/shots.mjs` serves `out/dashboard` on a temporary local HTTP server, drives Chrome at 1440×900, and writes three JPEGs of 300–350 KB. Re-run `main.ts` afterwards so `out/screenshots` and `dossier.json` match.
